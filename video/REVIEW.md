# REVIEW: 글 한 건의 여행 (첫 빌드)

## 만든 것
- SPEC.md의 스토리라인 B, 60초, 1920×1080(16:9), 30fps. 첫 빌드는 1080×1920(9:16)이었다. 사용자가 비율을 고른 적이 없는데 세로로 만들었고, 사용자 요청으로 가로로 다시 배치했다. 장면 11개(`compositions/s01`~`s11`)와 자막 1개(`captions.html`)로 나눴다.
- 책상(나무결)은 루트(`index.html`)에 있고, 장면이 바뀔 때마다 위로 540px 밀린다. 카드는 장면마다 같은 자리(왼쪽 칸 left 340, top 150)에서 시작하고 끝나서 컷이 이어져 보인다.
- 만들지 않은 안: A(빨강/초록 타이포), C(칠판).

## SPEC과 다른 점
- 첫 자막: "글 하나 올리는 데" → "글 하나 자동으로 올리기" (앞 문장만 있으면 말이 끊겨서)
- S11 자막: "코드는 됐는데, 계정이 안 된다" → "코드는 됐는데, 계정이 막혔다"
- 16:9 배치: 카드는 왼쪽 칸, 막는 물건은 오른쪽 칸. 카드가 상자·문으로 들어갈 때 아래 대신 오른쪽으로 간다. 자막은 아래 가운데(bottom 120).
- S14 폰: 높이 1080에 맞추려고 0.72배로 놓고 0.8배까지 푸시인(세로판의 1.0→1.12와 같은 비율).
- S11 열쇠: 시작 위치를 x -720에서 -1200으로 옮겼다(가로 화면에서는 -720이면 화면 안에서 보임).
- 도장은 잉크 빠짐 질감(마스크)을 없앴다. 질감을 넣으니 글자가 거의 안 읽혔다.
- **음악 없음.** 사용자가 배경음악은 넣지 않기로 했다. 효과음만 있다. SPEC의 "게시 순간 음악이 1박 비었다가 다시 들어옴"은 팝 효과음으로 대신한다.

## 확인한 것
- `check`: 통과. 남은 경고는 `duplicate_media_discovery_risk`(같은 사진이 카드 여러 장에 쓰임) 하나이며, 의도한 것이라 그대로 둔다.
- 스냅샷으로 장면마다 프레임을 봤다: 프레임 0(카드+`fatal:` 쪽지), 도장, 상자, 시계, 문, 벽, 메뉴, 열쇠, 열린 문, 게시 직전·직후, 끝 카드.
- 효과음은 각 파일의 피크 시각을 재서 그림보다 1프레임 뒤에 오게 배치했다. **소리는 측정만 했고 들어 보지 않았다.**
- 카드 속 캡션 글자에는 `data-layout-ignore`를 달았다. 이미 읽힌 카드가 장면마다 반복되어 읽기 시간 경고가 나는데, 거기서는 읽을 글이 아니라 물건이다.

## 약한 곳
- S14(게시 순간): 음악 없이 클라이맥스가 팝 효과음 하나에 기댄다.
- S11 열쇠 장면: 열쇠가 "토큰"이라는 건 자막이 있어야 읽힌다.
- 끝 카드 둘레는 나무결만 있어서 비어 보일 수 있다.
- 가로로 바꾸고 나니 폰(실제 게시물 화면)이 화면 높이에 맞춰 작아졌다. 게시물 글자는 읽히지 않고, 사진과 레이아웃으로 알아보는 정도다.
